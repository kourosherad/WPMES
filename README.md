# Wagon Pars Manufacturing Execution System

Phase 1 of the Wagon Pars production execution system. The application provides role-based production tracking, engineering-owned route definition, QR camera scanning, manual barcode entry, and project registration.

## Technology

- Node.js and React
- HTML/CSS interface
- SQL Server schema and migration baseline
- HTTPS-ready application server

## Run locally

```powershell
npm install
npm run build
npm start
```

The SQL Server deployment schema is available in `database/001_initial_schema.sql`.
